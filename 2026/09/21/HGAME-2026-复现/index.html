Endless Emails

题目分析

服务端使用相同的明文和较小指数 e = 3，向多个不同模数的 RSA 公钥发送密文。这是典型的 RSA 广播攻击：当收集到至少 3 组互素模数后，可以使用中国剩余定理恢复 m^3，再计算整数立方根得到明文。

成功计算出整数立方根后，输出的字节串就是 flag。

而 key 小于 70 bit，实际搜索范围很小。先用前三个输出拟合二次函数，再用第四个输出验证，得到初始状态的两个二次根候选，最后穷举 key。

解题步骤

  1. 使用 x1、x2、x3 建立关于 a、b、c 的线性方程组。
  2. 用模 n 的矩阵逆求出二次函数参数。
  3. 由 a*x0^2 + b*x0 + c = x1 得到关于 x0 的二次方程。
  4. 用 Tonelli-Shanks 求判别式平方根。
  5. 穷举 key，验证 shash 的结果。
  6. 对 I get the key now! 计算哈希，并按 VIDAR{...} 输出。

打好基础

题目文件是 stuck_out_tongue_.txt，内容经过多层 Base 编码。先识别 Base100，再依次处理 Base91、Base85、Base64 等编码层，直到得到明文。

这道题的重点是观察每一层字符集，而不是把所有内容当作同一种 Base 编码直接尝试。

魔理沙的魔法目录

题目提示需要阅读文章一小时。抓取请求后，发现请求头有时间戳，请求体中也有 time 属性。

将时间相关字段修改为满足题目条件的较大值后重新发送请求，即可通过校验并得到 flag。
