Luogu P16034：NavigableMap 与连锁更新

题目地址：P16034

这题使用 NavigableMap 维护有序 key 及其计数。当某个 key 的计数达到 5 后，它会被移除，同时把相邻 key 的计数各增加 1；相邻 key 达到阈值后继续递归处理。

实现要点

  • 使用 TreeMap 维护 key 的有序关系。
  • 通过 lowerKey 和 higherKey 找到左右邻居。
  • 用 TreeSet 保存待处理的 key，避免递归过程中反复扫描整个 Map。
  • 每次处理完一个达到阈值的 key 后再从 Map 中删除。

Java 实现

踩坑记录

这题最后卡在两个细节上：快读实现，以及对已删除 key 的重复处理。使用 map.remove() 后，如果后续又对同一个 key 做 put，需要确认这是否符合题目的连锁规则；不必要的删除和重复插入都可能导致 TLE。
